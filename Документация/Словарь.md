# Словарь терминов (Глоссарий) для системы автоматического тестирования

## Даты внесения изменений

| Версия                     | Дата            | Описание                                                                         | Автор    |
| -------------------------- | --------------- | -------------------------------------------------------------------------------- | -------- |
| Черновой начальный вариант | 20 ноября, 2025 | Первый черновой вариант глоссария для системы автоматического тестирования       | 5 группа |

## Определения

| Термин                                     | Определение                                                                         | Формат                           | Правило верификации                                                       | Синоним                 |
| ------------------------------------------ | ----------------------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------- | ----------------------- |
| Разработчик (Developer)                    | Пользователь системы, который создаёт, запускает и анализирует автоматические тесты | Роль в системе                   | Наличие доступа к репозиторию и среде выполнения                          | Тестировщик, Инженер    |
| Система автоматического тестирования (ATS) | Программная платформа для создания, выполнения и анализа автоматических тестов      | Программное обеспечение          | Проверка работоспособности перед запуском тестов                          | Test Automation System  |
| Тест-кейс (Test Case)                      | Отдельный сценарий тестирования, описывающий шаги, данные и ожидаемый результат     | Структура данных или скрипт      | Корректный синтаксис, наличие ожидаемого результата                       | Тестовый сценарий       |
| Тест-сьют (Test Suite)                     | Набор тест-кейсов, объединённых общей логикой или функциональностью                 | Группа тест-кейсов               | Должен содержать хотя бы один валидный тест-кейс                          | Набор тестов            |
| Среда выполнения (Test Environment)        | Инфраструктура, на которой выполняются автоматические тесты                         | Виртуальная или физическая среда | Доступность, соответствие требованиям тестов                              | Тестовая среда          |
| Запуск тестов (Test Execution)             | Процесс выполнения тест-кейсов в заданной среде                                     | Программный процесс              | Корректная конфигурация, доступность ресурсов                             | Прогон тестов           |
| Отчёт о тестировании (Test Report)         | Документ, содержащий результаты выполнения тестов                                   | Электронный документ или дашборд | Содержит статусы тестов, логи, время выполнения                           | Результаты тестирования |
| CI/CD система                              | Внешняя система непрерывной интеграции и доставки, инициирующая запуск тестов       | Программное API                  | Корректная интеграция, передача параметров запуска                        | Конвейер сборки         |
| Менеджер ресурсов (Resource Manager)       | Подсистема, управляющая выделением и освобождением тестовых ресурсов                | Модуль системы                   | Проверка доступности ресурсов перед запуском                              | Resource Controller     |
| Конфигурация теста                         | Набор параметров, определяющих условия выполнения теста (среда, данные, настройки)  | Конфигурационный файл            | Должна быть валидной и соответствовать тестовым требованиям               | Настройки теста         |
| Статус теста (Test Status)                 | Результат выполнения теста: Успех, Неудача, Пропущен, Ошибка                        | Перечисление (enum)              | Определяется по результату сравнения ожидаемого и фактического результата | Исход теста             |
| Сессия тестирования (Test Session)         | Время от запуска до завершения набора тестов                                        | Объект системы                   | Должна корректно завершаться генерацией отчёта и освобождением ресурсов   | Тестовый прогон         |
