### Прецедент: Настройка тестовой среды (SetupTestEnvironment)

Описание:  
DevOps-инженер или системный администратор настраивает тестовую среду для выполнения автоматических тестов.

---

Актёры:

- DevOps-инженер (DevOps): настраивает инфраструктуру и конфигурацию.
- Системный администратор (SysAdmin): управляет ресурсами и доступом.

---

Предусловия:

- Доступны необходимые ресурсы (серверы, контейнеры, виртуальные машины).
- Имеются права на настройку тестовых сред.
- Доступны конфигурационные файлы и скрипты развертывания.

---

Основной успешный сценарий:

1. DevOps-инженер выбирает тип среды для настройки (dev, staging, production-like).
2. Система проверяет доступность базовых ресурсов.
3. DevOps-инженер загружает конфигурационные файлы.
4. Система развертывает тестовую среду по шаблону.
5. DevOps-инженер настраивает специфические параметры (версии ПО, переменные окружения).
6. Система применяет конфигурацию и проверяет работоспособность.
7. DevOps-инженер тестирует подключение к среде.
8. Система сохраняет конфигурацию среды для последующего использования.

---

Диаграмма последовательности (Sequence Diagram):

```

@startuml
actor DevOps
participant EnvironmentManager
participant ResourceManager
participant ConfigManager
participant ProvisioningService

DevOps -> EnvironmentManager : Создать новую среду(type)
EnvironmentManager -> ResourceManager : Проверить доступность ресурсов
ResourceManager --> EnvironmentManager : Ресурсы доступны

DevOps -> EnvironmentManager : Загрузить конфигурацию(configFile)
EnvironmentManager -> ConfigManager : Валидировать конфигурацию
ConfigManager --> EnvironmentManager : Конфигурация валидна

EnvironmentManager -> ProvisioningService : Развернуть среду(config)
ProvisioningService -> ResourceManager : Выделить ресурсы
ResourceManager --> ProvisioningService : Ресурсы выделены

loop Для каждого компонента
  ProvisioningService -> ProvisioningService : Развернуть компонент
end

ProvisioningService --> EnvironmentManager : Среда развернута

EnvironmentManager -> DevOps : Запрос на настройку параметров
DevOps -> EnvironmentManager : Указать специфические параметры
EnvironmentManager -> ConfigManager : Применить параметры
ConfigManager --> EnvironmentManager : Параметры применены

EnvironmentManager -> EnvironmentManager : Запустить проверку работоспособности
EnvironmentManager --> DevOps : Среда готова к использованию

DevOps -> EnvironmentManager : Сохранить конфигурацию
EnvironmentManager -> ConfigManager : Сохранить шаблон среды
ConfigManager --> EnvironmentManager : Шаблон сохранен

@enduml
