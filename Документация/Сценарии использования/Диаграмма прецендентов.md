### Диаграмма прецедентов (Use Case Diagram)

```
@startuml
left to right direction

actor "DevOps-инженер" as DevOps
actor "Разработчик" as Developer
actor "QA-инженер" as QAEngineer
actor "Менеджер проекта" as Manager

rectangle "Система автоматического тестирования" {
  usecase "Настройка тестовой среды" as SetupEnv
  usecase "Запуск тестовой сессии" as RunTests
  usecase "Просмотр отчёта о тестировании" as ViewReport
  usecase "Анализ результатов тестирования" as AnalyzeResults
}

DevOps --> SetupEnv
Developer --> RunTests
Developer --> ViewReport
QAEngineer --> ViewReport
QAEngineer --> AnalyzeResults
Manager --> ViewReport
Manager --> AnalyzeResults

RunTests ..> SetupEnv : зависит от
ViewReport ..> RunTests : зависит от
AnalyzeResults ..> ViewReport : зависит от

@enduml
```
