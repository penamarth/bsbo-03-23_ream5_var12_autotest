### Прецедент: Просмотр отчета о тестировании (ViewTestReport)

Описание:  
Пользователь (разработчик, QA-инженер или менеджер) просматривает детализированный отчет о выполнении тестовой сессии.

---

Актёры:

- Разработчик (Developer): просматривает результаты своих тестов.
- QA-инженер (QAEngineer): анализирует общую картину тестирования.
- Менеджер проекта (Manager): оценивает метрики качества.

---

Предусловия:

- Тестовая сессия завершена.
- Отчет о тестировании сформирован и доступен.
- Пользователь имеет права доступа к отчету.

---

Основной успешный сценарий:

1. Пользователь открывает раздел отчетов в системе.
2. Система отображает список доступных тестовых сессий.
3. Пользователь выбирает нужную тестовую сессию.
4. Система загружает детализированный отчет.
5. Пользователь просматривает общую статистику (успешные/неудачные тесты, время выполнения).
6. Пользователь детально анализирует результаты отдельных тест-кейсов.
7. Пользователь просматривает логи и скриншоты (если доступны).
8. Пользователь экспортирует отчет в нужном формате (PDF, CSV, HTML).

---

Диаграмма последовательности (Sequence Diagram):

```
@startuml
actor User
participant ReportService
participant ReportGenerator
participant TestResultStorage
database "Хранилище отчетов" as ReportDB

User -> ReportService : Запрос списка отчетов
ReportService -> ReportDB : Получить список сессий
ReportDB --> ReportService : Список сессий
ReportService --> User : Отобразить список

User -> ReportService : Выбрать сессию(sessionId)
ReportService -> ReportDB : Получить отчет(sessionId)
ReportDB --> ReportService : Данные отчета

alt "Отчет не сформирован"
  ReportService -> ReportGenerator : Сформировать отчет(sessionId)
  ReportGenerator -> TestResultStorage : Получить результаты тестов
  TestResultStorage --> ReportGenerator : Результаты тестов
  ReportGenerator --> ReportService : Сформированный отчет
  ReportService -> ReportDB : Сохранить отчет
  ReportDB --> ReportService : Отчет сохранен
end

ReportService --> User : Отобразить отчет

User -> ReportService : Фильтровать/сортировать результаты
ReportService --> User : Обновленный вид отчета

User -> ReportService : Экспортировать отчет(format)
ReportService -> ReportGenerator : Создать экспорт(format)
ReportGenerator --> ReportService : Экспортированный файл
ReportService --> User : Файл отчета

@enduml
